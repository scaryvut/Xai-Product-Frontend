# 🚀 Xai – Intelligence Workspace

> Transforming **Raw Data → Structured Intelligence → Actionable Insights → AI Automations**

A modern, interactive SaaS landing page built with **Next.js**, **Tailwind CSS**, **Framer Motion**, **GSAP**, and **React Three Fiber**. The project focuses on immersive UI, smooth animations, and a premium user experience.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/your-username/xai-intelligence-workspace.git
```

Go to the project

```bash
cd xai-intelligence-workspace
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
